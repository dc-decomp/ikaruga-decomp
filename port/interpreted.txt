# Ninja, 0x8C010138 to Kamui's first function at 0x8C030F20, but for the functions that the
# port/src/ninja*.cpp files implement natively (port/replaced.txt).
# Ninja is hand-written assembly. It keeps the current matrix in the xf bank from one call to the
# next, passes values in FPU register pairs between routines, returns results in several registers
# and pushes registers below its frame. The decompiled C loses all of that: compared with the
# machine code (IKARUGA_SH4_TEST), njTranslate, njRotateX to njRotateZ and njInvertMatrix computed
