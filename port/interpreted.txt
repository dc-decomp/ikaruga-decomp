# Ninja, 0x8C010138 to Kamui's first function at 0x8C030F20, but for the matrix and trigonometry

# assembly. It keeps the current matrix in the xf bank from one call to the next, passes values
# in FPU register pairs between routines, returns results in several registers and pushes
# registers below its frame. The decompiled C loses all of that: compared with the machine code
